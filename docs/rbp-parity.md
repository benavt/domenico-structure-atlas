# RBP atlas parity adapter

The accepted 10,926-model snapshot remains the scientific population. Native
physicality flags are annotations, and ProteinEBM energy is never confidence.
The library scientific pin stays unchanged; presentation source is recorded
separately. All existing projection coordinates, inputs and prior runs survive.

`scripts/rbp_parity.py` runs only through an exact approved private plan and the
existing protected runner. It uses the frozen CASP17 native density primitive
(raw Cα distances → 10D UMAP → HDBSCAN leaf labels), recursively refining the
largest primary leaf for up to five rounds. Repeat seeds and EOM extractions
are diagnostics. Native noise and the historical unsplit-parent rule are recorded.
There are no invented matched historical child populations or landmark scores.

New assigned groups use the native confidence/medoid policy. Selected ensembles
receive complete medoid TM grids and Bonsai trees using their exact rows from the
verified distance cache, with all nonzero PCA axes and no whitening. The original
UMAP view receives its own Bonsai and TM artifacts. Empirical variance cores and
colors come from the original saved full-cohort evidence, independently of states.

TM≥0.80 states use all 271 construct positions, at least 50 members, and at most
three supported representative-relative neighborhoods. The bounded search may
miss modes; it never relaxes the cutoff or fills unsupported groups. The global
HDBSCAN/energy prior is conditioned on each state. MCMC uses four 10,000-step
chains and takes chain0's final50 distinct models; DISCO uses its separate saved
coverage/Plackett–Luce control. Completion does not establish chain convergence.

Native TM input mappings and bidirectional call intents/results are journaled
in SQLite. They remain private analysis caches. Interrupted native work is
preserved, and resuming it requires a separately reviewed exact recovery plan.
RAM-backed feature staging is released before Bonsai PCA; cgroup memory/CPU/
zero-swap controls and the existing host pressure/admission guards remain active.

The saved publisher retains every projection point and membership/score row,
while coordinate delivery contains only cluster representatives and the saved
MCMC50/DISCO50 panels. HDBSCAN is the default labeling; UMAP remains available.
`rbp_publish.py` verifies saved artifacts, attaches hash-bound state controls,
and exports the shared renderer once. It performs no scientific inference and
never deploys. Final camera-dependent figures and public replacement keep their
separate review gates. Previous public releases and full private inputs remain.
